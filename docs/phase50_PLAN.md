## 2. Scope decision (canonical roadmap, expanded to the full standard toolkit)

The roadmap mandates **SLERP + Task Arithmetic**. To make the phase genuinely *complete* and *perfect* for the well-established "Model Merging / Weight Averaging" field (the mergekit reference surface), I am expanding to the **full standard toolkit** and updating the roadmap to reflect it:

| Method | CLI `--method` | Inputs | Formula |
|---|---|---|---|
| Linear / Weighted avg (Model Soups) | `linear` | N inputs + weights | `out = Σ wᵢ·Mᵢ` (weights normalized to 1) |
| SLERP (spherical lerp) | `slerp` | N inputs + weights | pairwise chained `slerp`; `t=w₂/(w₁+w₂)` |
| Task Arithmetic | `task-arithmetic` | 1 base + N deltas + scales | `out = base + Σ sᵢ·(Mᵢ−base)` |
| TIES-Merging | `ties` | 1 base + N deltas + scales + density | trim→elect-sign→disjoint-merge onto base |
| DARE | `dare` | 1 base + N deltas + scales + density | drop-and-rescale deltas, then linear-combine onto base |

`linear` and `slerp` take `--inputs a,b,...` + `--weights w1,w2,...`.
`task-arithmetic`, `ties`, `dare` take `--base b` + `--deltas d1,d2,...` + `--scales s1,s2,...`; `ties`/`dare` also take `--density 0.5` (fraction of delta magnitude/params retained).

## 3. Hard guarantees (non-negotiable, per ARCHITECTURE_V4 §64)

1. **Validate before any write.** Architecture, tensor-name-set, per-tensor shape & dtype must match across all inputs (and base) **before** a single output byte is produced. Mismatches fail loudly via `AarambhError::Config` / `::Shape` / `::Checkpoint`.
2. **SLERP identity floor.** At `weight = 1.0` (or `0.0`), SLERP reproduces an input checkpoint **exactly** (bit-for-bit f32).
3. **Measured, not assumed.** A merged checkpoint's eval-harness scorecard is *reported* against the inputs' individual scores — never claimed to be an improvement without measurement.
4. **MoE is supported transparently** — merging operates on raw `HashMap<String, Tensor>` name/shape-matched maps, so MoE expert tensors merge identically to any other tensor. No special-casing, no `reject_moe_*`.
5. **CPU-first.** All math runs on `Device::Cpu` by default (merging is offline, not latency-sensitive). The crate's existing `cuda` feature is forwarded but not required.
6. **Zero `TODO`/`FIXME`/`unimplemented!()`** anywhere (release-audit enforces this).
7. **Every public item documented** with `///` (CI `cargo doc -D missing_docs`).
8. **`#![deny(missing_docs)]`** at the top of `merge.rs`.

## 5. `merge.rs` public API (design)

```rust
//! Model merging and weight averaging — Phase 50.
//! (crate doc with # Layout, # Honesty boundary — mirrors retrieve crate)
#![deny(missing_docs)]

/// The merge algorithm to apply.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum MergeMethod { Linear, Slerp, TaskArithmetic, Ties, Dare }

/// Per-tensor SLERP numerical guard: if the two flattened tensors are
/// near-parallel (cos θ > this), fall back to linear interpolation.
pub const SLERP_PARALLEL_EPSILON: f64 = 1.0 - 1e-6;

/// Configuration for a merge operation.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MergeConfig {
    pub method: MergeMethod,
    /// Per-input weights (linear/slerp). Normalized to sum=1.
    pub weights: Vec<f64>,
    /// Per-delta scales (task-arithmetic/ties/dare).
    pub scales: Vec<f64>,
    /// Fraction retained (ties: magnitude top-k%; dare: keep-probability). 0.0–1.0.
    pub density: f64,
    /// Normalize output deltas (ties/dare) — recommended default true.
    pub normalize: bool,
}

/// Report returned by a successful merge.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MergeReport {
    pub method: MergeMethod,
    pub input_count: usize,
    pub tensor_count: usize,
    pub output_path: PathBuf,
    /// True if SLERP fell back to linear for any tensor (parallel vectors).
    pub slerp_linear_fallback_count: usize,
    /// True if TIES reported sign-conflict resolution counts, etc.
    pub ties_resolved_tensors: usize,
    /// True if DARE dropped any params.
    pub dare_dropped_fraction: f64,
}

/// Merge compatible checkpoints into one SafeTensors file.
///
/// `inputs` are the N model paths for `linear`/`slerp`.
/// `base` + `deltas` are used for `task-arithmetic`/`ties`/`dare`
/// (`deltas` = independently-tuned checkpoints whose task-vector is `delta − base`).
pub fn merge_models_from_paths(
    config: &ModelConfig,
    inputs: &[PathBuf],            // for linear/slerp
    base: Option<&Path>,           // for task-arithmetic/ties/dare
    deltas: &[PathBuf],            // for task-arithmetic/ties/dare
    output: impl AsRef<Path>,
    merge: &MergeConfig,
) -> Result<MergeReport>;
```

## 6. Algorithm details

### 6.1 Common validation (`validate_inputs`)
1. Resolve which set of paths applies (inputs vs base+deltas) per method.
2. `candle_core::safetensors::load(path, &Device::Cpu)` each → `Vec<HashMap<String,Tensor>>`.
3. Verify all maps share the **same key set** (else `AarambhError::Checkpoint`).
4. For each shared key, verify **same shape & dtype** (else `AarambhError::Shape`).
5. Verify `weights.len()`/`scales.len()` matches input/delta count (else `AarambhError::Config`).
6. `density ∈ (0.0, 1.0]` for ties/dare (else `AarambhError::Config`).
7. All done **before** any arithmetic — no partial output.

### 6.2 Linear (Model Soups)
`out[k] = Σᵢ wᵢ · inᵢ[k]` with weights normalized. Single pass, elementwise `affine` + `add`.

### 6.3 SLERP
Per tensor (flattened to 1-D):
- `a`, `b` flattened; `dot = (a·b).sum_all()`; `na = ‖a‖`, `nb = ‖b‖`; `cosθ = dot/(na·nb)`.
- If `cosθ > SLERP_PARALLEL_EPSILON` (near-parallel) → linear fallback: `out = (1−t)·a + t·b` (increment `slerp_linear_fallback_count`).
- Else `θ = acos(cosθ)`; `out = (sin((1−t)θ)/sinθ)·a + (sin(tθ)/sinθ)·b`; reshape to original.
- For N>2 inputs: fold left-to-right, `tᵢ = wᵢ/(Σ_{j≤i} wⱼ)`.

### 6.4 Task Arithmetic
`deltaᵢ[k] = Mi[k] − base[k]`; `merged[k] = base[k] + Σᵢ sᵢ·deltaᵢ[k]`.

### 6.5 TIES-Merging (per delta, per tensor)
1. **Trim:** keep only the top-`density` fraction by absolute magnitude; zero the rest.
2. **Elect sign:** for each parameter position across all deltas, sign = sign of `Σ |deltaᵢ|·sign(deltaᵢ)` (weighted majority).
3. **Disjoint merge:** average only the deltas whose sign agrees with the elected sign; zero others.
4. `out = base + merged_delta`.

### 6.6 DARE (per delta, per tensor)
1. **Drop:** Bernoulli mask with keep-prob `density` (seeded RNG for determinism — `rand` 0.8 with fixed seed).
2. **Rescale:** surviving deltas multiplied by `1/density`.
3. Combine deltas linearly (with `scales`) and add to base.

### 6.7 Output
- `fs::create_dir_all(parent)`; `candle_core::safetensors::save(&merged_sorted, output)`.
- Sort tensor keys for deterministic output (mirror `gguf.rs:58-59`).
- Return `MergeReport`.
